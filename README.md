# Bank Churn: Logistic Regression vs Random Forest

השוואה בין שני מודלי סיווג, **רגרסיה לוגיסטית** ו-**Random Forest**, לחיזוי עזיבת לקוחות בנק (Churn), עם דשבורד HTML אינטראקטיבי.

**לצפייה בדשבורד:** https://nuritfiliba79-spec.github.io/churn-logistic-regression-vs-random-forest/

## מה יש בפרויקט

| קובץ | תיאור |

| `index.html` | הדשבורד: כותרת, שורת KPI ושלוש לשוניות |

## הנתונים

`churn_modelling.csv`: 10,000 לקוחות בנק, מתוכם **20.4% עזבו**. משתנה המטרה הוא `Exited` (1 = הלקוח עזב).

| עמודה | תיאור |
|---|---|
| `CreditScore` | דירוג אשראי |
| `Geography` | מדינה (France, Germany, Spain) |
| `Gender` | מגדר |
| `Age` | גיל |
| `Tenure` | ותק בבנק (שנים) |
| `Balance` | יתרה בחשבון |
| `NumOfProducts` | מספר מוצרים בבנק |
| `HasCrCard` | מחזיק כרטיס אשראי (0/1) |
| `IsActiveMember` | לקוח פעיל (0/1) |
| `EstimatedSalary` | שכר משוער |
| `Exited` | **משתנה המטרה** (1 = עזב) |

העמודות `CustomerId` ו-`Surname` הוסרו, כי הן מזהות לקוח ואין בהן מידע שעוזר לחזות עזיבה.

## שיטה

1. **חלוקה אקראית: 80% אימון (8,000) ו-20% מבחן (2,000).** החלוקה מרובדת (`stratify=y`), כך ששיעור העוזבים זהה בשתי הקבוצות. `random_state=42` מבטיח שהתוצאות יחזרו על עצמן.
2. **עיבוד מקדים:** `StandardScaler` למשתנים המספריים ו-`OneHotEncoder` למדינה ולמגדר. העיבוד הוא חלק מה-Pipeline, ולכן הוא נלמד מנתוני האימון בלבד.
3. **מודלים:**
   - `LogisticRegression(max_iter=1000)`
   - `RandomForestClassifier(n_estimators=300, random_state=42)`
4. **הערכה על נתוני המבחן בלבד**, בסף החלטה 0.5.

## השוואה לפי הקריטריונים

| קריטריון | Logistic Regression | Random Forest | המודל העדיף |
|---|---|---|---|
| **Recall** | 0.187 | **0.469** | Random Forest |
| **Precision** | 0.589 | **0.770** | Random Forest |
| **F1 Score** | 0.284 | **0.583** | Random Forest |
| **ROC** | נמוכה יותר | **גבוהה יותר כמעט בכל הטווח** | Random Forest |
| **AUC** | 0.775 | **0.854** | Random Forest |

מדדים נוספים:

| מדד | Logistic Regression | Random Forest |
|---|---|---|
| Accuracy (מבחן) | 0.808 | 0.864 |
| Accuracy (אימון) | 0.811 | 1.000 |
| R² (על ההסתברות) | 0.168 | 0.354 |
| MAE (על ההסתברות) | 0.272 | 0.218 |
| עוזבים שזוהו | 76 / 407 | 191 / 407 |
| התראות שווא | 53 | 57 |

## מסקנות

- **Random Forest עדיף בכל חמשת הקריטריונים.** הוא מזהה 191 מתוך 407 לקוחות שעזבו, לעומת 76 ברגרסיה הלוגיסטית, כמעט בלי להוסיף התראות שווא (57 לעומת 53).
- **ה-Accuracy של הרגרסיה הלוגיסטית (0.808) מטעה.** כ-80% מהלקוחות לא עוזבים, ולכן מודל שתמיד עונה "לא עוזב" יקבל Accuracy של כ-0.80. לכן Recall, Precision ו-F1 הם המדדים החשובים כאן.
- **Random Forest "לומד בעל פה" את נתוני האימון** (Accuracy 1.0 באימון לעומת 0.864 במבחן). הגבלה של עומק העצים (`max_depth`) יכולה לשפר את ההכללה.
- **המשתנים החשובים ביותר:** גיל הוא בין החשובים בשני המודלים. ברגרסיה הלוגיסטית בולטים גם מדינה (גרמניה), לקוח פעיל ומגדר. Random Forest נותן משקל גבוה גם ליתרה, לשכר, לדירוג האשראי ולמספר המוצרים.

## הדשבורד

- **כותרת ושורת KPI:** Recall, Precision, F1, ROC AUC, R² ו-MAE לשני המודלים.
- **לשונית 1, השוואה לפי הקריטריונים:** טבלת השוואה עם המודל העדיף בכל קריטריון, גרף עמודות של המדדים ועקומת ROC.
- **לשונית 2, בפועל מול חזוי:** גרף של שיעור העזיבה בפועל מול ההסתברות החזויה, והתפלגות השאריות.
- **לשונית 3, חשיבות משתנים:** כמה כל משתנה השפיע על החיזוי בכל אחד מהמודלים.

> **R², MAE ושאריות בבעיית סיווג:** המשתנה החזוי הוא ההסתברות לעזיבה (0 עד 1), והערך בפועל הוא 0 או 1. המדדים מחושבים על ההסתברות, והשארית היא `בפועל − הסתברות חזויה`.

כל הגרפים משתמשים באותה פלטת צבעים: כחול לרגרסיה לוגיסטית וכתום ל-Random Forest. יש מצב כהה, ובמעבר עכבר מוצגים הערכים המדויקים.
