# Bank Churn: Logistic Regression vs Random Forest vs XGBoost

השוואה בין שלושה מודלי סיווג, **רגרסיה לוגיסטית**, **Random Forest** ו-**XGBoost**, לחיזוי עזיבת לקוחות בנק (Churn), עם דשבורד HTML אינטראקטיבי.

**לצפייה בדשבורד:** https://nuritfiliba79-spec.github.io/churn-logistic-regression-vs-random-forest/

## מה יש בפרויקט

| קובץ | תיאור |
|---|---|
| `index.html` | הדשבורד: כותרת, שורת KPI ושלוש לשוניות |
| `data.js` | התוצאות שהדשבורד מציג (נוצר על ידי `train_model.py`) |

## הנתונים

`churn_modelling.csv`: 10,000 לקוחות בנק, מתוכם **20.4% עזבו**. משתנה המטרה הוא `Exited` (1 = הלקוח עזב).

| עמודה | תיאור |
|---|---|
| `CreditScore` | דירוג אשראי |
| `Geography` | מדינה (France, Germany, Spain) |
| `Gender` | מגדר |
| `Age` | גיל |
| `Tenure` | ותק בבנק (שנים) |
| `Balance` | יתרה בחשבון |
| `NumOfProducts` | מספר מוצרים בבנק |
| `HasCrCard` | מחזיק כרטיס אשראי (0/1) |
| `IsActiveMember` | לקוח פעיל (0/1) |
| `EstimatedSalary` | שכר משוער |
| `Exited` | **משתנה המטרה** (1 = עזב) |

העמודות `CustomerId` ו-`Surname` הוסרו, כי הן מזהות לקוח ואין בהן מידע שעוזר לחזות עזיבה.

## שיטה

1. **חלוקה אקראית: 80% אימון (8,000) ו-20% מבחן (2,000).** החלוקה מרובדת (`stratify=y`), כך ששיעור העוזבים זהה בשתי הקבוצות. `random_state=42` מבטיח שהתוצאות יחזרו על עצמן.
2. **עיבוד מקדים:** `StandardScaler` למשתנים המספריים ו-`OneHotEncoder` למדינה ולמגדר. העיבוד הוא חלק מה-Pipeline, ולכן הוא נלמד מנתוני האימון בלבד.
3. **מודלים:**
   - `LogisticRegression(max_iter=1000)`
   - `RandomForestClassifier(n_estimators=300, random_state=42)`
   - `XGBClassifier(max_depth=4, learning_rate=0.1, n_estimators=100, random_state=42)`
4. **הערכה על נתוני המבחן בלבד**, בסף החלטה 0.5.

## השוואה לפי הקריטריונים

| קריטריון | Logistic Regression | Random Forest | XGBoost | המודל העדיף |
|---|---|---|---|---|
| **Recall** | 0.187 | 0.469 | **0.474** | XGBoost |
| **Precision** | 0.589 | 0.770 | **0.791** | XGBoost |
| **F1 Score** | 0.284 | 0.583 | **0.593** | XGBoost |
| **ROC** | הנמוכה ביותר | גבוהה | **הגבוהה ביותר ברוב הטווח** | XGBoost |
| **AUC** | 0.775 | 0.854 | **0.872** | XGBoost |

מדדים נוספים:

| מדד | Logistic Regression | Random Forest | XGBoost |
|---|---|---|---|
| Accuracy (מבחן) | 0.808 | 0.864 | 0.868 |
| Accuracy (אימון) | 0.811 | 1.000 | 0.879 |
| R² (על ההסתברות) | 0.168 | 0.354 | 0.392 |
| MAE (על ההסתברות) | 0.272 | 0.218 | 0.204 |
| עוזבים שזוהו | 76 / 407 | 191 / 407 | 193 / 407 |
| התראות שווא | 53 | 57 | 51 |

## מסקנות

- **XGBoost עדיף בכל חמשת הקריטריונים**, ו-Random Forest קרוב אליו מאוד. שני מודלי העצים טובים בהרבה מהרגרסיה הלוגיסטית: הם מזהים פי 2.5 יותר לקוחות שעוזבים (193 ו-191, לעומת 76).
- **XGBoost גם מכליל טוב יותר.** ה-Accuracy שלו באימון (0.879) קרוב לזה שבמבחן (0.868), כלומר הוא כמעט לא "לומד בעל פה". Random Forest, לעומת זאת, מגיע ל-1.0 באימון.
- **ה-Accuracy של הרגרסיה הלוגיסטית (0.808) מטעה.** כ-80% מהלקוחות לא עוזבים, ולכן מודל שתמיד עונה "לא עוזב" יקבל Accuracy של כ-0.80. לכן Recall, Precision ו-F1 הם המדדים החשובים כאן.
- **המשתנים החשובים ביותר:** הגיל חשוב בכל המודלים. ב-XGBoost בולטים מספר המוצרים, לקוח פעיל וגיל. Random Forest נותן משקל גבוה לגיל, לשכר, לדירוג האשראי וליתרה. ברגרסיה הלוגיסטית בולטים מדינה (גרמניה), גיל ומגדר.
- **אפשר לשפר עוד:** Recall של כ-0.47 אומר שעדיין כמחצית מהעוזבים לא מזוהים. הורדת סף ההחלטה מתחת ל-0.5, או שקלול המחלקות (`scale_pos_weight` ב-XGBoost), יגדילו את ה-Recall במחיר של יותר התראות שווא.

## הדשבורד

- **כותרת ושורת KPI:** Recall, Precision, F1, ROC AUC, R² ו-MAE לשלושת המודלים.
- **לשונית 1, השוואה לפי הקריטריונים:** טבלת השוואה עם המודל העדיף בכל קריטריון, גרף עמודות של המדדים ועקומת ROC.
- **לשונית 2, בפועל מול חזוי:** גרף של שיעור העזיבה בפועל מול ההסתברות החזויה, והתפלגות השאריות.
- **לשונית 3, חשיבות משתנים:** כמה כל משתנה השפיע על החיזוי בכל אחד מהמודלים (RF: Gini, XGBoost: gain, רגרסיה לוגיסטית: גודל המקדם).

> **R², MAE ושאריות בבעיית סיווג:** המשתנה החזוי הוא ההסתברות לעזיבה (0 עד 1), והערך בפועל הוא 0 או 1. המדדים מחושבים על ההסתברות, והשארית היא `בפועל − הסתברות חזויה`.

כל הגרפים משתמשים באותה פלטת צבעים: כחול לרגרסיה לוגיסטית, כתום ל-Random Forest וירוק ל-XGBoost. יש מצב כהה, ובמעבר עכבר מוצגים הערכים המדויקים.
